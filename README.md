# Сводка

Локальное веб-приложение: следит за мессенджером Авито через официальный API и показывает новое входящее сообщение.

Пароль от Авито не используется. Нужны Client ID и Client Secret из кабинета: «Для профессионалов» → API, с доступом `messenger:read` и `user:read`. Мессенджер по API доступен на платном тарифе («Базовый», «Расширенный» или «Максимальный»).

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте http://127.0.0.1:3780

Ключи сохраняются в `data/state.json` на этом компьютере. Пока страница открыта, приложение само спрашивает Авито (по умолчанию раз в 30 секунд) и может показать уведомление браузера. Чат в Авито при этом не помечается прочитанным.

Порт и адрес: переменные `PORT` и `HOST`. По умолчанию сервер слушает только `127.0.0.1`.

## Вебхук

Если нужна доставка, когда вкладка закрыта, Авито может сам прислать событие на публичный https-адрес. Поднимите туннель до этого сервера, вставьте адрес в настройках и нажмите «Подписать Авито». Сервер ответит на `POST /api/webhook?token=...`.

## Cloudflare Workers

Страница и API работают на одном адресе `*.workers.dev`. Опрос Авито идёт по таймеру внутри Durable Object и продолжается, когда вкладка закрыта. Ключи хранятся в хранилище Cloudflare, не в репозитории.

```bash
npm install
npx wrangler login
npm run cf:dev
```

Публикация:

```bash
npx wrangler secret put APP_PASSWORD
npm run cf:deploy
```

`APP_PASSWORD` закрывает страницу. Вебхук Авито этот пароль не спрашивает: у него отдельный token в адресе. Для локальной проверки пароль можно положить в файл `.dev.vars` строкой `APP_PASSWORD=секрет`. Без этой переменной локальный `wrangler dev` открыт без пароля.
